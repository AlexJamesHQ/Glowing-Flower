This project is an **interactive portfolio and realistic typing effect** web application, designed to showcase a modern, immersive UI experience. It features a clean, dark-themed aesthetic with animated flower backgrounds, firefly particle effects, and a highly customizable "human-like" typing animation.

### Live Demo
[https://glowing-flower-alex.vercel.app](https://glowing-flower-alex.vercel.app)

## Features

- **Interactive Typing Experience**: Realistic typing simulation with particle effects.
- **Dynamic Animations**: Includes an animated background feature (Flower Bloom effect).
- **Speech Input**: Voice-to-text integration for easier interaction.
- **Customization**: Users can input custom text for animation, with a history feature to replay previous entries.
- **Responsive Design**: Optimized for mobile and desktop viewports, mimicking iOS-style controls.
- **History Management**: Stores and retrieves previous text animation inputs locally in the browser.

## Technologies Used

- **HTML5 & CSS3**: Core structure and styling, utilizing modern CSS features like backdrop-filter and custom animations.
- **JavaScript (Vanilla)**: Handles the logic for typing simulation, canvas rendering, speech recognition, and local storage.
- **Canvas API**: Used for rendering high-performance particle effects and glowing elements.
- **Web Speech API**: Powers the voice-to-text functionality.

## Usage

1.  **Type**: Simply type directly on the screen to trigger the animated text effect.
2.  **Voice**: Click the microphone icon to use voice input.
3.  **Animation**: Use the Play button to set custom text for an automated typing sequence.
4.  **History**: Access the history menu to see and replay past animations.
5.  **Clear**: Use the backspace/clear icon to remove words individually with a dissolving animation.
